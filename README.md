# Commerce Admin App

Standalone admin dashboard built with React, Vite, Tailwind CSS, and Redux Toolkit.

## Features

- Admin login with JWT
- Dashboard metrics and recent orders
- Add products
- Edit products
- Deactivate products
- View and update order status
- View registered users

## Run

Start the backend first:

```powershell
cd "C:\Users\hp\Documents\admin app\server"
npm start
```

Then start the admin app:

```powershell
cd "C:\Users\hp\Documents\admin app\admin-app"
npm install
npm run dev
```

Open the Vite URL, usually:

```text
http://localhost:5173
```

Default seeded admin login:

```text
admin@example.com
Admin@123
```
